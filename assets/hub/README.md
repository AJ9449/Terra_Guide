# Hub overview

Hub is where execution gets planned. It sits in the Planning phase and
maps test cases and scenarios onto a real release timeline.

## Node hierarchy

Project → Release → Iteration → RunPlan → Folder → Hub Flow / Relay

- **RunPlan** — maps testcase or Hub Flow execution to a date range
- **Relay** — the master execution that consolidates every Hub Flow into
  one run
- **Hub Flow** — stacks test cases and scenarios the same way Automation's
  Flow node stacks Keyword and Script
