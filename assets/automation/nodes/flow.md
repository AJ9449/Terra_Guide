# Flow

*Keyword + Script pairing*

**What it is.** Combines a Keyword and a Script under one node.

{% hint style="info" %}
**Why it exists.** Some actions are naturally a hybrid — mostly a standard keyword action with one script-driven twist — Flow keeps that pairing as a single reusable unit.
{% endhint %}

**Who uses it:** Automation engineers packaging a keyword+script combination that keeps recurring

## Setting it up

{% stepper %}
{% step %}
Open Automation → Folders → Flow.
{% endstep %}
{% step %}
Pick the Keyword and Script that pair together.
{% endstep %}
{% step %}
Combine them under one Flow node.
{% endstep %}
{% step %}
Drop the Flow into a Testcase — QA never touches the underlying script.
{% endstep %}
{% endstepper %}
