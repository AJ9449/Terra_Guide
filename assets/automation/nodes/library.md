# Library

*Reusable collection*

**What it is.** A stacked, reusable collection of Keywords, Scripts, and Formulas.

{% hint style="info" %}
**Why it exists.** Grouping related building blocks — everything needed to test a login flow, say — makes them easier to find, version, and hand off between teams.
{% endhint %}

**Who uses it:** Automation engineers organizing a growing shared toolkit

## Setting it up

{% stepper %}
{% step %}
Open Automation → Folders → Library.
{% endstep %}
{% step %}
Group the Keywords, Scripts, and Formulas that belong together.
{% endstep %}
{% step %}
Name and version the Library.
{% endstep %}
{% step %}
Hand it off to the team that needs that toolkit.
{% endstep %}
{% endstepper %}
