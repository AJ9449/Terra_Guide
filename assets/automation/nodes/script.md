# Script

*Custom logic*

**What it is.** Custom logic for cases the built-in keywords do not cover.

{% hint style="info" %}
**Why it exists.** Not everything is a standard input or verify — Script is the escape hatch for one-off or complex logic, like a workaround for a flaky third-party widget.
{% endhint %}

**Who uses it:** Automation engineers with coding experience, brought in when a keyword genuinely is not enough

## Setting it up

{% stepper %}
{% step %}
Open Automation → Folders → Script.
{% endstep %}
{% step %}
Write the custom logic the built-in keywords can't cover.
{% endstep %}
{% step %}
Test it against the specific case that needed it.
{% endstep %}
{% step %}
Save and reference it from a Testcase, or wrap it in a Flow.
{% endstep %}
{% endstepper %}
