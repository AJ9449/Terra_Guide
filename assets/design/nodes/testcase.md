# Testcase

*Single executable test*

**What it is.** A single executable test, built by dragging nodes from Model's repositories into a flow.

{% hint style="info" %}
**Why it exists.** It is the atomic unit of Design — every other Design concept is built by combining test cases.
{% endhint %}

**Who uses it:** QA engineers building and maintaining day-to-day test coverage

## Setting it up

{% stepper %}
{% step %}
Create a new TC node under a Region.
{% endstep %}
{% step %}
Drag the nodes you need from the Custom pallet into the Public flow.
{% endstep %}
{% step %}
Configure each step's data from the Info block.
{% endstep %}
{% step %}
Save and deploy.
{% endstep %}
{% endstepper %}
