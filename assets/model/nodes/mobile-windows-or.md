# Mobile OR · Windows OR

*Mobile & Windows object repositories*

**What it is.** The same repository concept as WOR, adapted for mobile app screens and Windows desktop applications.

{% hint style="info" %}
**Why it exists.** Mobile and desktop UI frameworks expose elements differently than a web DOM, so each needs its own capture format.
{% endhint %}

**Who uses it:** Mobile or desktop QA engineers onboarding a new application

## Setting it up

{% stepper %}
{% step %}
Open Model → Application → Mobile OR (or Windows OR).
{% endstep %}
{% step %}
Connect the target device or desktop app through the recorder.
{% endstep %}
{% step %}
Capture the screens and controls you need.
{% endstep %}
{% step %}
Save to make them available to Design.
{% endstep %}
{% endstepper %}
